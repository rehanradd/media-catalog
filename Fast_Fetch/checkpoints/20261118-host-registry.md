**2. Prober learns moves (`Fast_Fetch/fast_probe.py`, `Fast_Fetch/check_host_roots.py`).** `_probe_host` records a redirect observation after `head_chain`, in ADDITION to verdicts — verdict policy, writer, and locking untouched. Threshold **20** (`REDIRECT_MOVE_THRESHOLD`): one redirect proves nothing (CDN hop, short-link, parked page); 20 distinct host-only redirects to the same new host is overwhelmingly likely the service itself; a big host crosses it in one 5,000-row sweep batch (per-host cap ~208), a small host needs several batches; counts persist in the observations sidecar (`host_redirect_observations.json`, gitignored) across runs. Host-only rule: an observation counts only when the redirect keeps the same path + query (scheme may flip); redirects to a bare IP never count. Root-check script probes every registry host root, reports alive/moved/blocked/down/gone, records one observation per move candidate, `--json` output, exit 0 always. `validate_host_move` (fetcher-injectable): old-root redirect → rewritten file URL 200 → new-root 200; 403/429 = blocked, never dead.
